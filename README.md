# Sorab U Rajput - Portfolio

This is a modern, responsive portfolio website built with React, Vite, and Tailwind CSS.

## Features
- **3D Interactive Background**: Custom "Floating Lines" effect using Three.js.
- **Animations**: Smooth entry animations with Framer Motion and "SplitText" for the hero section.
- **Glassmorphism UI**: Stylish cards and sections with glassmorphism effects.
- **Responsive Design**: Fully responsive layout for all devices.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Three.js
- Framer Motion

## Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/sorab0961/sorab-portfolio.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
4.  Build for production:
    ```bash
    npm run build
    ```
